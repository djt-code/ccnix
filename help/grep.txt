grep: print the lines that match a pattern (POSIX grep)

  grep [-E|-F] [-c|-l|-q] [-inrsvx] -e patterns ... [-f file] ... [file...]
  grep [-E|-F] [-c|-l|-q] [-inrsvx] patterns [file...]
  grep -r pattern [dir...]          (the files under each dir, all the way down)

Patterns are basic regular expressions (-E: extended, -F: fixed strings); a pattern list holds one pattern per line, and a line is selected if any of them matches.  -e gives a list (repeatable), -f reads one from a file.  -i ignores case, -x matches whole lines only, -v selects the lines that do NOT match.  Output: the lines, prefixed with "file:" when there are several files and "number:" with -n; -c prints a count per file instead, -l the names of the files with a selected line, -q nothing.  -s hides the messages about unreadable files.  No files (or "-") reads standard input (the keyboard: hold Ctrl+T to end it). -r (or -R: CC has no links to tell apart), as GNU's and BSD's grep have it: a directory operand stands for every file under it, in name order, each line prefixed with its file; no operands searches the current directory (the names without "./"). Exit status: 0 a line was selected, 1 none, 2 an error (0 with -q if a line was selected anyway).
