Position persistence:
T.dataPath(name) - The path of a data file kept next to the running program (/ccnix/turtle for one in the ROM), moving an old copy down the first time it's asked for.
T.savePos() - Write T.pos, T.dir and T.mode to the position file, so a stop or a reboot can still find the way home. Raises "Terminated" if a Ctrl+T was held back (see T.run).
T.run(fn, ...) - Run fn(...) so that Ctrl+T can't leave the saved position wrong: one that comes during a turtle command is held back until the move or turn is saved.
T.loadPos() - The saved position as { x, y, z, dir, mode }, or nil if there is none.
T.frameId() - The number of the frame the turtle counts in: one more at each re-zero that moves 0,0,0 (0 before the first).
T.frameStale(stamp) - Why a job saved in frame `stamp` can't be carried on now (a re-zero since), or nil if it can.
T.clearPos() - Delete the saved position file: the next job starts from home as (0,0,0).
T.startAtHome(force) - Call at the start of a job: the turtle is at home, facing forward. If a saved position says otherwise, returns it instead of resetting so the program can warn the user.
The turtle API, wrapped once:
T.claim() - Make this module the one the wrapped turtle functions keep up to date. Loading turtlelib does it already; call it when another program's module may have loaded since (claude, after run_program).
T.owns() - Is this copy of turtlelib the one the wrapped turtle functions keep up to date (the last loaded, or the last to T.claim)? A module's listener that acts for its program (the undo journal, autoDump) acts only while its copy owns the turtle.
T.onChange(fn) - Call fn(event) for every successful dig, placement and move from now on, by any program on this turtle; event.kind is "dig", "change", "place" or "move", with x, y, z. Returns a function that removes the listener.
T.protect(name, x1, y1, z1, x2, y2, z2) - Protect the box between two corners (x, y, z in the turtle's frame, either order) under `name`: a dig into it returns false, "protected: <name>" (placing and moving in it are not stopped). True, or nil and why.
T.unprotect(name) - Remove the area called `name`. True, or false and why (none by that name).
T.areaSet(names) - The names in `names` (one area's name, a list or a set of them) as a set { [name] = true }; an empty set for nil.
T.protected(x, y, z, skip) - The name of the first protected area that holds the cell, or nil. `skip`, a name or a list of names, leaves those areas out (see T.guarded).
T.protections() - The protected areas, as a list of { name, x1, y1, z1, x2, y2, z2 } (copies: changing one changes nothing).
T.guarded(x, y, z) - The name of the protected area that stops the current job from digging the cell: T.protected, but not counting the areas the job is working inside (T.cfg.inside, set by T.inside). nil if none.
T.inside(names, fn, ...) - Run fn(...) as a job that owns the protected areas `names` (one name, or a list): digging in them is allowed meanwhile (other areas still hold). Puts it back after, even if fn errors (the error goes on); returns fn's results.
T.withUnprotected(names, fn, ...) - Run fn(...) with digging allowed in the protected areas `names` (one name, or a list): T.inside by another name.
T.neverDig(name) - Is this block one the dig functions refuse (a container, spawner or ComputerCraft block)? mine's own list of blocks never to dig.
T.turnRight() - Turn a quarter turn to the right, keeping T.dir and the saved position right.
T.turnLeft() - Turn a quarter turn to the left, keeping T.dir and the saved position right.
T.face(d) - Turn to face heading d (0 to 3, as T.dir) by the shorter way.
T.faceToward(x, z) - Face toward an adjacent column.
T.posString() - The position as "(x,y,z)".
T.setDir(d) - The heading is really d (a program worked it out from what's round the turtle: the saved one can be off after a stop between a turn and its save, or a turtle put back by hand).
T.lookAround() - What's beside the turtle, by quarter turns to the right of the way it faces: seen[a] is the inspect data at a turns, or false for air.
Fuel:
T.hasFuel(n) - Is there fuel for n moves? (Always, with fuel turned off.)
T.refuelTo(target) - Burn fuel from the inventory until the tank holds `target`. Only what T.fuel lists is burnt: logs, planks, sticks, chests and crafting tables burn too, but they're what chests and torches are made from.
T.homeCost() - Fuel to get home from here: straight-line moves by default. Programs that travel at a set height or dig down to a chest override it.
T.ensureFuel() - Called before every move: when the tank is short of the trip home plus T.cfg.fuelMargin, tops it up from the inventory; if that isn't enough, runs T.fuelTrip, else waits for the user once truly out.
T.totalFuelAvailable() - Fuel in tank plus the fuel value of the T.fuel items in the inventory. Burns nothing.
T.requireFuel(needed) - Block until at least `needed` fuel is available (tank + inventory), filling the tank up to `needed` from inventory first.
Tool upgrades:
T.isTool(name) - Is the item `name` a tool (a pickaxe, hoe, shovel, axe or sword)?
T.emptySlot() - The first empty slot, or nil if there is none.
T.findSlot(what) - The first slot holding `what` (an item name, or a function(name, item) that picks one); nil if none.
T.equipped(side) - Name of the item equipped on `side`, or nil. Uses getEquippedLeft/Right (CC:Tweaked 1.110+); older versions are probed by swapping through an empty slot, which needs one free slot.
T.findTool(suffix) - A tool whose name ends with `suffix` ("_pickaxe"): the one equipped, else the first in the inventory; nil if there's none.
T.usePrimaryTool(name) - Equip `name` from the inventory if it isn't already, unequip any OTHER tool into the inventory, and return a function that restores the original arrangement. Errors if the tool is nowhere on the turtle.
T.withTool(name, fn) - Run fn with `name` as the only equipped tool, restoring the original tools afterwards even if fn errors (the error is re-thrown).
T.equipTool(name, side) - Back-compat: equip `name` onto `side` from the inventory, if present.
Peripheral upgrades:
T.equipPeripheral(name, opts) - Equip the item `name` on the side that holds no chunk controller (or kept side), and wait for it to show up. Returns the peripheral and a function that puts back what was there, or nil and why.
T.withPeripheral(name, fn) - Run fn(peripheral) with the item `name` equipped as a peripheral, and put back what was on that side afterwards. Returns true and what fn returned, or nil and why it couldn't equip (see T.equipPeripheral).
Low-level moves:
T.up() - Move up one block, digging what T.diggable lists and attacking what's in the way (fuel first): true, or false and why. It stops at T.cfg.maxHeight, 16 above the start by default.
T.down() - Move down one block, digging what T.diggable lists and attacking what's in the way (fuel first): true, or false and why. It stops at T.cfg.maxDrop, 12 below the start by default.
T.forward() - Move forward one block, digging what T.diggable lists and attacking what's in the way (fuel first): true, or false and why ("blocked by <block> at x,y,z", "couldn't dig ...", "can't move forward: ..." or "no fuel").
T.back() - Back up a block without turning (saves turning round to go back the way it came). It can't see or dig behind it: false and why if anything is there ("can't move back: something is in the way").
T.settle() - Sink until resting on something solid.
T.toY(y) - Climb or sink to height y in the current column.
T.toStartHeight() - Return to y = 0.
T.below() - What is directly below: a block name (or "air"), plus inspect details.
Six directions:
T.sideDir(side) - The direction a side (CC's "front", "top", "bottom", as for chests) is in from the turtle as it faces now.
T.here() - A copy of T.pos: { x, y, z }.
T.at(p) - Is the turtle at p ({ x, y, z })?
T.posKey(p) - The key "x,y,z" for a position p.
T.keyPos(k) - Inverse of posKey: the x, y, z of "x,y,z" (whole numbers, as posKey writes them); nil if k isn't one.
T.dist(a, b) - The taxicab distance between two positions.
T.neighbour(d) - The block next to the turtle in direction d.
T.dirTo(p) - The direction from the turtle to the block next to it at p.
T.look(d) - Face direction d (0 to 3, "up" or "down") and inspect there: returns turtle.inspect's ok, data.
T.digDir(d) - Face direction d (0 to 3, "up" or "down") and dig there, through the wrapped dig, so a protected area holds. Returns turtle.dig's results (false and why if it can't).
T.placeDir(d, text) - Face direction d (0 to 3, "up" or "down") and place the selected item there; text is written on a sign. Returns turtle.place's results.
T.attackDir(d) - Face direction d (0 to 3, "up" or "down") and attack there. Returns turtle.attack's results.
T.suckDir(d) - Face direction d (0 to 3, "up" or "down") and pick up items there. Returns turtle.suck's results.
T.moveDir(d) - Move one block in direction d (T.up/T.down/T.forward: digging what T.diggable allows, attacking what's in the way).
Liquids and falling blocks:
T.liquidNear(x, y, z) - The liquid that would flow into the cell x, y, z (or a table { x, y, z }) if it were opened: its name and cell, or nil.
T.isFalling(name) - Does this block fall when what is under it goes (sand, gravel, concrete powder, an anvil, ...)?
T.cellSet(spec) - The cells of a list or set (opts.digOnly) as a set of "x,y,z" keys, or nil and why.
T.moveTo(x, y, z, opts) - Move to x, y, z, digging only what opts.dig allows: true (and a warning, if any), or false, why, the block and cell that stopped it. opts: order, dig, digOnly, avoid, inside, liquid; path = true hands a blocked run to T.travel.
T.digCell(x, y, z, opts) - Dig the one block at x, y, z and nothing else: go beside it (the path finder, digging nothing), dig it. True, the block's name (nil: it was empty) and a warning (sand over it); or false and why.
T.trail() - The breadcrumb trail: the cells the turtle moved through lately (up to 200), oldest first, as { x, y, z }; the last is where it moved to last.
T.retrace(n, opts) - Walk back along the trail over the last n cells (default all of it), skipping loops. True and the moves made, or false, why and the moves made.
T.turnsTo(d) - Turns it takes to face direction d (none for up or down).
T.eachAround(skip, fn) - Call fn(d) with each direction but `skip`, the fewest turns away first (so up and down, and the way it faces, come before any turn).
T.stepToward(p) - A step toward p (nearer by taxicab distance), the one needing the fewest turns; nil when there.
Obstacle map (2D, by column) and BFS routing:
T.ckey(x, z) - The key "x,z" for a column.
T.keyXZ(k) - Inverse of ckey: the x, z a key ("x,z") was made from; nils if k isn't one.
T.markBlocked(x, z) - Mark column x, z as blocked, for T.bfs and T.goTo.
T.clearBlocked() - Forget every column marked blocked.
T.inBounds(x, z) - Is column x, z inside the routing area (T.cfg.width and length, plus T.cfg.margin)?
T.bfs(tx, tz) - Shortest column path from the current position to (tx,tz), or nil.
Column-stepping strategies:
T.stepFlat() - Flat: stay at the current height.
T.stepTerrain() - Terrain: climb up to maxClimb to get in, then sink onto the ground. A drop deeper than maxClimb is a crevasse: back out and mark it.
T.goTo(tx, tz) - Navigate to column (tx,tz) with BFS + re-planning.
T.coverColumn(x, z) - Stretch the routing area (cfg.width/length) so it takes in column (x,z) too: a turtle stopped outside it, on a farm bigger than the defaults or one lying left of or behind home, would otherwise have no route at all.
T.goHome(opts) - Return to the start from wherever the saved position says we are (used by the `reset` subcommands and home.lua). Returns true if home.
T.setHomeHere() - `reset --here`: the turtle was put back at home by hand, so accept where it is (facing forward) as home without moving.
T.requireHome(force, prog) - Start a job: startAtHome, but when the saved position says the turtle is elsewhere, print the standard warning (naming the program's reset command) and return false so the program can stop.
T.setting(name, default, description) - A setting from CC's settings (`sysctl mine.width=5` at the prompt), defined here so `sysctl -d` describes it with its description; its default where there is no settings API.
T.saveSettings(values) - Keep values given on the command line ({ [name] = value }) as the settings, so the next run without them (or the autostart) uses them.
T.options(args, long) - Parse a program's command-line `args` with lib/getopt, options and operands in any order. Returns the options table and the operands, or nil and why.
T.loadMineJob() - The job: { width, height, length (nil: no end), spacing, homes, frame, state, stale }, or nil if there's none or it isn't one.
T.saveMineJob(job) - Save a job as loadMineJob reads it back, stamped with the frame it was made in (job.frame, else this one).
T.hasMineJob() - Whether a mine.job file is there at all (a job that can't be read still counts: mine was given one).
Plans:
T.serpentine(width, length) - Serpentine over the grid: columns along x, rows alternating in z. Tiles are counted OUT from the start: x = 1..w, z = 1..l (signed), so the start tile (0,0) is never part of the plan.
T.lightLattice(radius, width, length) - Positions for light sources so that every tile of the grid is within taxicab distance `radius` of one. Returns a set keyed by T.ckey and an ordered list.

T.isContainer(name) - Is the block name a chest or a barrel?

T.ensureRoom(need, keepCount, goDump, warning) - Make sure at least `need` slots are free before working a tile whose drops must not spill, calling goDump() (the trip to the chest) if short. Returns true, or false once still short (printing `warning` once).

T.travel(x, y, z, opts) - Go to the cell x, y, z by the map: along a clear layer if there is one, else by a search; true (and T.moveTo's warning, if it dug under sand or gravel), or false and why.
Looking at what came out, and taking it back:
T.forgetPlacements(family) - Forget what T.placeAt has learnt (the data file .placements), for one family ("stairs", "slab", "torch", ... as T.placeInfo names them) or for all. True, or false and why.
Placing a block with the state wanted:
T.placeInfo(item) - What placeAt can place this item by: { family, keys, hang, door }, or nil if the item is not a block it knows.
T.placeAt(x, y, z, item, opts) - Place item at the cell x, y, z with the state wanted (opts.facing, opts.half, opts.axis; a sign's opts.text): the block, its state and how; nil and why if it can't.
Lighting a fire:
T.ignite(x, y, z, opts) - Light a fire in the cell x, y, z with flint and steel, from above: the fire's name, or nil and why.
The list of chests, in a data file:
T.addChest(x, y, z, side, bulk) - Tell the turtle about a chest: it stands at x, y, z (the turtle's frame) and the chest is on `side` ("up"/"top", "down"/"bottom", or a heading 0 to 3 as T.dir counts them). True (and a note if it was known), or nil and why.
T.forgetChest(x, y, z, side) - Forget the chest at this place (as T.addChest was given it, or another stand for the same chest). True, or false and why.
T.chests() - The chests the turtle knows, as a list of { x, y, z, side, bulk, seen, other, items = { name = count } }; seen is when the chest was last read (seconds, the clock T.catalogue uses), 0 if never; other is the other half's cell of a double chest.
Going to a chest:
T.recount(side) - Read the known chest on `side` of the turtle ("front", "top"/"up", "bottom"/"down") again, into the list of chests. The chest as T.chests gives it, or nil and why.
Cataloguing:
T.catalogue(spots, opts) - Go round the chests and write down what each holds. Returns true, info; false, why, info when some could not be read; nil, why when there is nothing to do.
Where an item is, and fetching it:
T.where(name) - Which chests hold the item `name` (or a glob of item names; the namespace may be left out), as written down: a list of { x, y, z, side, count, bulk, seen, age }, the nearest to the turtle first, and the total. Moves nothing.
T.fetch(name, n, opts) - Go to the chests that hold `name` and take n of it (default 1), then come back facing as before (opts.stay: stay at the last chest). Returns how many came aboard, and why if that is short of n.
What there is, everywhere:
T.inventoryReport(opts) - Every item across the chests (as last read) and the turtle, with totals, sorted by name: a list of { name, total, turtle, chests, places, age }, and info { kinds, items, chests, oldest, text }. Moves nothing.
Putting away:
T.stow(opts) - Put what the turtle carries away in the chests: into one that already holds the item, else into the bulk chest. Returns true, info; false, why, info when something stayed aboard; nil, why if no chest is known.
Getting ready for a job:
T.prepare(spec) - Get ready for a job in one trip, T.prepare{ need = { [name] = n }, freeSlots = k }: stow what isn't needed, fetch what is, come back, check the room. True, info; false, why, info (what is short, too few slots free); nil, why.
T.autoDump() - Make room: stow what is not kept (T.stow), or dump the junk (T.dumpJunk) if there are no chests; T.cfg.autoDump = true runs it when the inventory is nearly full. The results are those of the one it ran; nil and why if neither is set up.
Frames and the world:
T.frameChanged(old, new) - Tell the map the turtle's frame changed: the spot that was `old` ({x, y, z, dir}) is now `new` (default 0,0,0 facing 0). turtlelib calls it; returns true, or false and why.
T.alignMap(dx, dy, dz, turns) - Say how the turtle's frame sits in the map's, and mark the map aligned. Returns true, or nil and why.
T.origin() - The turtle's frame in the world: { x, y, z, facing, aligned }, the world cell of its (0,0,0) and the compass way its +z points. Nil and why if T.setOrigin hasn't been told.
T.setOrigin(x, y, z, facing) - Say where the turtle stands in the world: world cell (x, y, z), facing "north", "east", "south" or "west". Returns true and T.origin()'s table, or nil and why.
T.toWorld(a, b, c) - Convert a point of the turtle's frame (a table with x, y, z, or three numbers) to the world's: a table { x, y, z }; nil and why if there's no origin or the map is unaligned.
T.toLocal(a, b, c) - Convert a world point (a table with x, y, z, or three numbers) to the turtle's frame: a table { x, y, z }; nil and why if there's no origin or the map is unaligned.
The map:
T.map.get(x, y, z) - What the map holds at x, y, z (turtle frame): the block's name, its state table if inspected, and when it was last seen (seconds); nil and why if never seen.
T.map.set(x, y, z, name, state) - Note a cell in the map by hand: the block `name` (nil: forget it) at x, y, z of the turtle's frame, with its state table if it's known. True, or nil and why. (Digs, placements, moves and scans note themselves.)
T.map.top(x, z, lo, hi) - The y of the highest solid cell known in the column x, z (not air, water, lava or fire), and its name; nil and why if the map knows none. lo and hi (optional) keep to the cells from y lo up to y hi.
T.map.find(pattern, box, limit) - The cells in the box (whole map if none) whose block name matches the glob, nearest first: a list of {x, y, z, name}, and true if cut to `limit` (default 500).
T.map.count(pattern, box) - How many cells inside the box (the whole map if none) hold a block whose name matches the glob (as in T.map.find). Nil and why if the map is unaligned.
T.map.heights(box) - A height map of the box (17 by 17 about the turtle if none) as text: each column's highest solid y, "." where none is known.
T.map.slice(y, box) - The layer at height y in the box (17 by 17 about the turtle if none) as text, a character a cell, with a legend of the symbols.
T.map.flush() - Write what has changed to disk now (it is written in batches as it goes). True, or false and why.
T.map.stats() - What the map takes: { cubes, bytes, cap, unsaved, aligned, kept, pins, over }: how many cubes, how many bytes they take on disk, the most it may take, how many cubes have changes not written, and whether it is aligned.
T.map.pin(box) - Keep the cubes of a box (six numbers in the turtle's frame, or x1 to z2 fields) when the map is over its cap. True, or nil and why.
T.map.unpin(box) - Let a pinned box go (the same six numbers T.map.pin was given), or every pin with no box. True, or false and why.
T.map.clear() - Throw the map away: every cube (and every pin) is deleted. An unaligned map becomes aligned again, with the turtle's frame as its own (and the world origin is forgotten, as it was set against the old frame).
T.map.frame() - The frame the map is in relation to the turtle's: { turns, dx, dy, dz, aligned } (see T.alignMap).
T.map.toMap(x, y, z) - A point of the turtle's frame in the map's: mx, my, mz (T.map.frame says how they relate).
T.map.fromMap(mx, my, mz) - A point of the map's frame in the turtle's: x, y, z.
T.map.cube(cx, cy, cz) - The cube at cx, cy, cz (map frame) as its 4096 bytes and its palette, for code that reads many cells at once; nil if there is none.
Scans:
T.scan(r, opts) - Geo-scan around the turtle (radius r, default 8; over 8 needs opts.force) into the map: { ["x,y,z"] = name } in the turtle's frame, and an info table.
T.mergeScan(entries, r, opts) - Put a scan somebody else took, here, in the map: true and the number of blocks in it, or nil and why.
T.scanBox(box, opts) - Scan a whole box ({x1, y1, z1, x2, y2, z2}, turtle frame) with radius-8 scans side by side, nearest next: { tiles, scanned, failed }.
Inspecting:
T.inspectAt(x, y, z, opts) - Go next to the cell x, y, z, inspect it and note its block and state in the map: name, state table (nil if none), or nil and why.
T.inspectAll(list, opts) - T.inspectAt for each cell of a list ({x, y, z} tables or "x,y,z" keys), nearest next: { ["x,y,z"] = {name, state} } and a list of {x, y, z, why} that failed: the way to get block states over an area (T.scan gives names only).
